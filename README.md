# مجلتي وروتيني 🌸

موقع **وتطبيق قابل للتثبيت** (PWA) لمساحتك الشخصية: مقالاتك وروتينك اليومي.
يعمل على الجوال والحاسوب، ويعمل **دون إنترنت**، ويحفظ بياناتك **مشفّرة على جهازك**.

> ✨ مبني بلا أطر عمل ثقيلة: Node + Express على الخادم، وJavaScript قياسي على العميل.
> كل ميزة في مجلدها الخاص، وكل ميزة داخلية في ملفها الخاص.

---

## التشغيل السريع

```bash
npm install          # مرة واحدة
npm start            # يبني ثم يشغّل على http://localhost:3000
```

| الأمر | الوظيفة |
|---|---|
| `npm start` | بناء الأصول + تشغيل الخادم |
| `npm run dev` | نفس الشيء مع إعادة تشغيل تلقائي |
| `npm test` | اختبارات API والترميز وترتيب PDF وصفحات الصور (107 اختبارًا) |
| `npm run check` | فحص الصياغة + الاستيرادات + الاختبارات (بوابة الجودة) |
| `npm run build` | فقط بصمة البناء وختم إصدار Service Worker |
| `npm run icons` | إعادة توليد الأيقونات PNG من الكود |
| `npm run backup` | نسخة احتياطية مضغوطة لبيانات الخادم |

**للتشغيل في الإنتاج:** انسخ `.env.example` إلى `.env`، واضبط `SESSION_SECRET` (إلزامي)، ثم:

```bash
NODE_ENV=production npm start
```

## الميزات

### 🏠 الشاشة الرئيسية (لوحة اليوم)
بعد تسجيل الدخول تُفتح الصفحة الرئيسية مباشرة على **روتينك** لا على صفحة تعريفية:

- **شريط ترحيب** بالاسم والتاريخ المحلي، وحلقة تقدّم اليوم، وثلاث إحصاءات (سلسلة الأيام، أفضل سلسلة، التزام الأسبوع).
- **سطر تحفيزي** يتغيّر حسب تقدّمك اليومي (أنت تنجح أكثر في الصباح، بقي روتين واحد…).
- **زر «العودة للرئيسية»** في هيدر كل الصفحات الداخلية (روتيناتي، المدرب، الحساب، الخزنة…).
- **قائمة روتينات اليوم**: اضغط الدائرة للإنجاز، أو ↷ للتخطّي، أو ✦ لإرسال تذكير لهذا الروتين تحديدًا.
- **اقتراحات ذكية** جاهزة للإضافة بضغطة — تُفلتَر تلقائيًا حسب ما لديك (تتعرف على الأرقام العربية أيضًا).
- **إعدادات التذكير** مختصرة، ورابط سريع لصفحة الروتينات.

### ✅ روتيناتي (`/routines`)
- إنشاء وتعديل وحذف الروتينات مع أيقونة ولون ووقت ومدة وأيام تكرار.
- تصفية (الكل / اليوم / بمواعيد / المؤرشفة)، بحث وفرز، وإنجاز أو تخطّي مباشر.
- نسخ روتين، أرشفة واستعادة بدل الحذف الفوري، وتذكير فوري.
- إحصاءات الأسبوع: سلسلة حالية، أفضل سلسلة، نسبة الالتزام، وإنجاز اليوم، مع خريطة أيام الأسبوع.
- سلسلة مستقلة لكل روتين تظهر على بطاقته، وملخص أسبوعي في العمود الجانبي.
- **٥ أنظمة روتين جاهزة** في مجلدات مستقلة، تُضاف بدفعة واحدة وبلا تكرار، مع خطوات صغيرة ومحفّز بدء لكل روتين.
- **إنجاز نهائي لهذا اليوم**: الروتين المنجز يختفي من قائمة الانتظار ويُحفظ في السجل؛ لا يمكن إلغاء إنجازه بعد الآن.
- **٢٤ ساعة**: أي روتين بلا وقت أو أيام يبقى متاحًا طوال اليوم بدل أن يفوته وقته.
- **مكتبة ٢٩ قالبًا** في ٧ تصنيفات داخل نافذة الإضافة، مع معاينة حيّة وخطوات ومحفّز وأهمية وطاقة.
- **تطور الروتين**: XP ومستويات وست مراحل (بذرة → برعم → نمو → إزهار → إتقان → أسطورة)، ولوحة «تطورك» في الصفحة.
- **مركز القيادة**: زر واحد يفتح ١٢٠ قدرة — تحليلات ٩٠ يومًا، مهمة اليوم، تحديات وشارات، أهداف، مفكرة، تركيز، قوالب، تصدير/استيراد، وإجازة.
- **سجلي وفحص النظام**: آخر ٣٠ يومًا من الإنجاز، وفحص متكامل للأنظمة والمكتبة والإكمال والإشعارات.

### 🧠 أنظمة الروتين الخمسة (`server/features/routines/systems/`)
كل نظام مجلد مستقل يحتوي ثلاثة ملفات: `manifest.json` (الهوية والمراحل)، `routines.json`
(الروتينات بخطواتها ومحفّزها)، و`brain.js` (عقل النظام الذي يقرأ سجلك ويقيّم توافقك).

| النظام | الفكرة | عدد الروتينات |
|---|---|---|
| `deep-focus` — التركيز العميق | نافذتان محميتان + صيام إشعارات + إغلاق يومي | ٧ |
| `energy` — الطاقة الحيوية | ماء وضوء صباحًا، حركة موزعة، نوم يصلح الغد | ٧ |
| `calm` — الهدوء الذهني | تنفس وتدوين ومشي صامت وإغلاق ليلي | ٧ |
| `builder` — البناء والتعلم | تعلم قصير، استرجاع نشط، كتابة، قراءة، مراجعة أسبوعية | ٧ |
| `balance` — التوازن الشامل | أولويات، حركة، تواصل إنساني، تدوين، نوم مبكر | ٨ |

- **عقل مشترك** (`systems/engine.js`): يطبّع النصوص العربية، يحسب الالتزام لكل نافذة وقت،
  ويكتشف الروتينات المتأخرة والأساسيات الناقصة.
- **تقييم شخصي**: كل `brain.js` يعيد نسبة توافق + إشارات + خطوتين تاليتين، ويُدمج التقييم في `/api/routines/coach`.
- **تفعيل ذكي**: `full` (كل النظام) أو `core` (الأساسيات) أو `light` (بداية خفيفة)،
  ووضع `replace` يؤرشف القديم قبل الإضافة. التكرار يُمنع بمقارنة العناوين المطبّعة.

### 📚 مكتبة القوالب والإكمال (`server/features/routines/library/` و`completion/`)
- `library/manifest.json` + `library/routines.json`: ٢٩ قالبًا عربيًا في ٧ تصنيفات (جسد، ذهن، عمل، بيت، علاقات، مال، روح).
- `library/index.js`: تطبيع، تحقق، بحث وتصنيف، و`libraryHealth()` لفحص المكتبة.
- `completion/evolution.js`: XP حسب الأهمية، منحنى مستوى ١٫٣٥×، ست مراحل، و`hydrateProgress` لترحيل آمن للبيانات القديمة.
- `completion/index.js`: مصدر الحقيقة لتغيير حالة اليوم (done/skipped) وكتابة التطور والسجل في كتابة ذرّية واحدة.

### 🚀 مركز قيادة الروتين (`/routines` ← «مركز القيادة»)
لوحة واحدة تجمع **١٢٠ قدرة** موزعة على ١٢ مجموعة، فوق محرك تحليلي يقرأ سجل ٩٠ يومًا في تمريرة واحدة:

- **القيادة اليومية**: المستوى الكلي و XP، الزخم مقابل الأسبوع السابق، السلسلة، نسبة الالتزام،
  الأيام المثالية، دقائق العناية، الحمل اليومي، خطر الإرهاق، وتوقع الوصول للمستوى القادم.
- **مهمة اليوم الواحدة**: يختارها المحرك حسب الأولوية والوقت والطاقة والتعثر، مع زر إنجاز نهائي.
- **أفضل خطوة تالية**: اقتراح قابل للتنفيذ (جدولة، موازنة، تركيز) وزر يطبّقه.
- **التحليلات**: خريطة حرارية ٩٠ يومًا، أداء أيام الأسبوع، توزيع الأولوية والطاقة والأنظمة،
  أوقات الإنجاز، ملخص الشهر، الروتينات المتعثرة، والاستمرارية.
- **التحديات والشارات**: ٧ تحديات و٢٤ شارة تُحسب من السجل نفسه، مع استلام المكافأة مرة واحدة.
- **صحة العادات**: التزام/سلسلة/قوة كل روتين، مفضلة، وسوم، إيقاف مؤقت ٧ أيام واستئناف.
- **الأهداف والمراجعات**: ١٠ أنواع أهداف قابلة للقياس (إنجازات، سلسلة، دقائق، مستوى…) مع موعد
  ومكافأة، ومراجعات يومية/أسبوعية/شهرية/ربع سنوية.
- **المفكرة والتركيز**: تدوينة يومية بمزاج وطاقة، جلسات تركيز، وحذف أي إدخال.
- **الأدوات**: مخطط تلقائي (جدولة/موازنة/تركيز)، تصدير JSON و ICS و CSV و Markdown،
  استيراد JSON، قوالب شخصية، وإعدادات (هوية، احتفال، بيئة، ميزانية يوم، إجازة).
- **الإجازة**: `vacationUntil` يوقف الروتينات مؤقتًا ككل، ويعيدها تلقائيًا عند إلغائها.
- **آمن**: كل كتابة ذرّية، والحدود (٣٠ هدفًا، ٣٠ قالبًا، ٨ وسوم…) مفروضة على الخادم.

### 📚 كتبي (`/books`)
مكتبة شخصية تقرأ ملفاتك كما هي، دون رفعها إلى الخادم:

- **صيغ مدعومة:** PDF (نصي أو ممسوح ضوئيًا)، EPUB، DOCX، CBZ (أرشيف صور/مانغا)، TXT، Markdown، HTML، RTF، CSV، JSON، والصور.
- **أربع طرق قراءة في قارئ واحد:** بدّل بينها في أي لحظة ولا تفقد موضعك:
  **تدفّق** (عمود واحد يتدفّق كتابًا كاملًا ويحمّل كل فصل عند الاقتراب منه)،
  **صفحات** (فصل مقسوم إلى صفحات حقيقية بتقليب أفقي وحركات ناعمة)،
  **مزدوج** (صفحتان متجاورتان على الشاشات الواسعة)، و**تركيز** (فقرة واحدة في كل مرة
  بلا تشتيت). زر الطريقة في الشريط السفلي يبدّلها بضغطة، والمفتاح `M` يدور بينها،
  والمفتاح `A` يشغّل التمرير التلقائي (سرعة ١–٥) الذي يقلّب الصفحات أو ينتقل بين الفقرات
  أو يمرّر التدفّق حسب الطريقة الحالية.
- **قارئ تدفّق جديد بالكامل:** بدل تقطيع الفصل إلى صفحات، يتدفّق الكتاب كاملًا في عمود قراءة واحد
  يتكيّف مع الشاشة. كل فصل يُحمَّل عند الاقتراب منه فقط، مع فهرس فصول قابل للبحث،
  **بحث داخل الكتاب كله** مع قفز وإبراز الكلمة، **إشارات مرجعية متعددة**، شريط تقدّم ذكي،
  اختصارات لوحة المفاتيح، وواجهة جديدة (شريط علوي رقيق + بطاقة كتاب + لوحات منسدلة).
- **أغلفة تلقائية:** يستخرج غلاف EPUB/PDF/CBZ/الصورة من الملف نفسه، ويولّد غلافًا فنيًا
  من العنوان والمؤلف للكتب النصية. يمكن استبدال الغلاف بصورة شخصية من المكتبة أو من بطاقة الكتاب.
- **نظام قراءة أدق:** حفظ الموضع كنسبة داخل الفصل + نسبة تقدّم في الكتاب، استعادة الموضع بعد تغيير
  الخط أو العرض أو الشاشة، وحفظ فوري عند الخروج أو إخفاء الصفحة.
- **نص PDF العربي في اتجاهه الصحيح:** إعادة بناء السطور من العناصر البصرية، فصل الأعمدة وقراءتها
  بالترتيب، تطبيع أشكال الحروف، وإصلاح الجمل التي كانت تظهر معكوسة أو متداخلة — بما فيها
  **الأسطر المختلطة عربي/إنجليزي** (الكلمة الإنجليزية تبقى مقروءة لا معكوسة).
- **صفحات PDF كصور دائمًا:** كل صفحة PDF تُعرض كصورة عالية الجودة (حتى ٣٠٠ صفحة، مع أولوية
  للصفحات التالفة بعد ذلك) لتفادي تشويه النصوص العربية من خطوط الملفات. يُحفظ النص المستخرج
  معها مخفيًا للبحث والمساعد، ويمكن التبديل إلى «النص المستخرج» من «مظهر القراءة».
- **كشف PDF التالف داخليًا:** إذا كانت الحروف نفسها مرتّبة خطأً في الملف (لا في القارئ)، يظهر تنبيه
  واضح للمستخدم بدل عرض نص مشوّش بلا تفسير.
- **نظام خطوط متكامل:** ثلاث عائلات عربية متغيّرة محليّة (Cairo للعناوين، Noto Sans Arabic
  للواجهة، Noto Naskh Arabic للقراءة) مع أوزان وأحجام وإيقاع أسطر مضبوط يمنع التداخل،
  و`fonts.css` مستقل يُحمّل مسبقًا. كل الأصول محليّة وتعمل دون إنترنت.
- **قارئ بخط القراءة:** يطبّق عائلة Naskh المريحة على كل كتاب مضاف
  (PDF أو EPUB أو DOCX أو نص)، مع ٦ ثيمات قراءة وحجم الخط والتباعد وضبط النص وعرض العمود.
- **تخزين مشفّر على الجهاز** عبر `features/save` (AES-GCM + IndexedDB + OPFS)، وفهرس خفيف للمكتبة.
- **مساعد القراءة (محادثة ذكية):** وضعه الافتراضي **تلخيص فقط**: تقول له «لخّص» فيقول لك ماذا
  تقول الصفحة في جملتين، بلا شرح ولا مقدمات ولا تكرار. **كل رسالة محادثة مستقلة** لها بطاقة
  سؤال وردّها الخاص، فلا يكتب رد جديد فوق رد قديم ولا تختلط إجابات الرسائل السابقة.
  يقبل صفحة واحدة أو عدة صفحات («صفحة ٧»، «الصفحات ٥–٨»، «صفحة ٥ و٧ و١٢») ويعرض سطرًا لكل
  صفحة، ويبحث في الكتاب كله عند السؤال. مخطط الأفكار لا يظهر إلا إذا طلبته صراحةً.
  النص يمرّ بطبقة تنظيف عربية (NFKC، إزالة محارف الاتجاه، بلا كسر كلمات) وخط Noto Sans Arabic
  واحد، فلا حروف ناقصة/مكررة ولا تلخبط بين الخطوط. مجلد المساعد كامل:
  `server/features/books/assistant/` و`public/features/assistant/`.
- **مجلس نماذج مجاني، مدمج تلقائيًا:** Pollinations بـ **١٢ نموذجًا** (openai-fast، openai، mistral، llama-fast، deepseek،
  gemini، openai-large، llama، deepseek-r1، gemini-thinking، qwen-coder، searchgpt) بلا مفتاح. كل سؤال يمرّ على أكثر من
  نموذج، ثم تُقيَّم الإجابات عربيًا (سلامة الحروف، الطول، تغطية الكلمات، الحشو) ويُختار
  الأفضل وتُدمج الكلمات والنقاط بلا تكرار. **ما تحتاج تختار نموذجًا ولا تضيف مفتاحًا**.
  إذا كانت النماذج مشغولة يُستخدم الملخص المحلي فورًا بلا رسالة خطأ. النتائج المتكررة
  تُحفظ ٤ دقائق في ذاكرة مؤقتة لتوفير الحصة. لا توجد أي مطالبة بإضافة مفتاح في الواجهة.
- **قراءة صور مجانية ثنائية اللغة:** OCR عربي + قراءة إنجليزية تقريبية لنفس الصورة،
  ثم تصحيح عربي مشترك (مسافات، حروف مقطوعة، أرقام) قبل التلخيص. لا توجد خطوة إعداد ولا
  مطالبة بمفتاح ولا تحذير «قد يكون فيه خطأ». ملف الكتاب يبقى على جهازك.
- **صور أو نص:** زر سريع أعلى القارئ يبدّل بين «صور الصفحات» و«النص المستخرج»، مع نفس الخيار
  داخل «مظهر القراءة».
- **الكتب الكبيرة:** تقسيم تلقائي للفصول الضخمة إلى أجزاء قابلة للترقيم، وترميز تشفير على دفعات
  بدل تمرير الملف كاملًا إلى المتصفح — فلا تتوقف الاستيراد بسبب حجم الكتاب.
- **مرتبطة بالحساب:** لكل حساب مكتبته وتفضيلات قراءته وموضعه الأخير؛ لا تظهر كتب حساب لآخر على الجهاز نفسه.
  المكتبة القديمة تُرحَّل تلقائيًا مرة واحدة إلى أول حساب يفتح «كتبي»، وتُمسح مكتبة الحساب عند حذفه.
- الكتب لا تُرفع إلى الخادم؛ يُرسل نص الصفحة الحالية فقط عند طلب المساعدة.

### 🔔 إشعارات القراءة والأصوات
- **إشعار أول كتاب:** ترحيب بإطلاق المكتبة، ويظهر في صندوق الإشعارات لحظيًا.
- **إشعار إتمام كتاب:** عند الوصول إلى 100٪، مرة واحدة لكل كتاب، مع رابط العودة للمكتبة.
- **تذكير القراءة:** يوميًا في وقت تختاره إن لم تقرأ، من صفحة «كتبي» أو تفضيلات الحساب، مع زر «جرّب الآن».
- **مزامنة القراءة:** يُرسل الخادم عنوان الكتاب/الفصل والنسبة والدقائق فقط (الكتاب يبقى على الجهاز)،
  فيعمل تذكير القراءة والملخص اليومي حتى لو كان التطبيق مغلقًا لعدة أيام.
- **إحصاءات القراءة:** أيام القراءة، سلسلة الأيام، ودقائق القراءة الإجمالية تظهر في صفحة «كتبي».
- **نظام أصوات موحّد** مبني على Web Audio بلا ملفات: تقليب الصفحة، الإشارة المرجعية، نجاح الحفظ،
  إتمام روتين اليوم، وصول إشعار، رد المساعد، وخطأ/تحذير. يُولَّد داخل المتصفح ويعمل دون إنترنت.
- **تحكم من أكثر من موضع:** زر كتم في الهيدر، لوحة التفضيلات (تشغيل + مستوى + تجربة)،
  واختبار صوت من صفحة الإشعارات. التفضيل يُحفظ في الحساب ويُزامَن بين الأجهزة.

### 🖼️ صورة الحساب
- رفع صورة PNG/JPG/WebP مع قصّ وتصغير تلقائي في المتصفح (384px)، والتحقق من الأبعاد والحجم على الخادم.
- تظهر في بطاقة الحساب وفي هيدر كل الصفحات، ويمكن إزالتها والعودة للأحرف الأولى.

### ✦ المدرب الذكي (`/coach`)
نظام ذكاء اصطناعي للروتين يعمل **دائمًا وبلا إنترنت وبلا مفاتيح** عبر محرّك قواعد
يحلّل سجلّك الحقيقي (`server/features/routines/ai/`):

| الملف | الوظيفة |
|---|---|
| `insights.js` | نسبة إنجاز كل روتين، أفضل نافذة وقت، أضعف يوم، الروتينات المتعثرة |
| `plan.js` | خطة اليوم مرتّبة: الوقت ← الطاقة ← الأهمية، مع كشف «فات وقته» |
| `advice.js` | نصائح مخصّصة من قواعد سلوكية (تبسيط الخطوة، نقل الوقت، تقليل الحِمل…) |
| `index.js` | يجمّع النتائج + طبقة **LLM اختيارية** (OpenAI / Anthropic) |

المدرب يكتشف مثلًا: «أنجزت هذا الروتين ٢٠٪ من المرات — جرّب تبسيط خطوته الأولى»،
أو «عدد روتينات اليوم كبير، اختر ثلاثًا»، أو «أفضل نافذة لك هي الصباح بنسبة ٨٥٪».
المساعد يستخدم **النماذج المجانية فقط** ويدمجها تلقائيًا. بلا أي مفتاح يعمل نصيًا عبر
Pollinations ويقرأ صور الصفحات بالـOCR العربي. لإضافة رؤية أدق، أضف مفتاح Gemini المجاني من
«إعدادات المساعد» أو `GOOGLE_API_KEY`، وأي مفتاح Groq/OpenRouter/Mistral مجاني يندمج تلقائيًا
عبر متغيّرات البيئة. لإيقاف السحابة المجانية إداريًا: `AI_CLOUD=off` (يبقى OCR والمحرك المحلي).

### ⏰ نظام التذكير والإشعارات الذكية
- **مجدول خادمي** يفحص كل دقيقة: تذكير الروتين عند دخول موعده، دفعة مسائية للمتبقي، وخطة صباحية.
- **متابعة الغائب**: تذكير روتين واحد يوميًا عند أول موعد مستحق (حتى بعد أسابيع من عدم الفتح)،
  وملخص يومي للغائب — بلا إغراق وبلا تكرار.
- **تذكير قراءة خادمي**: يعمل من تفضيل الحساب ولقطة القراءة المزامنة — لا يحتاج التطبيق مفتوحًا.
- **ملخص يومي صباحي** (وقت تختاره): روتينات اليوم + متابعة الكتاب.
- **رسالة عودة بعد الغياب**: إن غاب المستخدم يومين أو أكثر، تذكير ودّي بخطوة واحدة (كل يومين ثم أسبوعيًا).
- **حصاد أسبوعي** يوم الأحد مساءً: نسبة الالتزام والسلسلة والقراءة.
- **تنبيهات أمان**: دخول من جهاز جديد وتغيير كلمة المرور وإنجازات السلاسل (7/14/30…).
- **حماية من التكرار**: كل تذكير مرة واحدة يوميًا لكل روتين (مسجّل في `nudges` داخل ملف المستخدم)،
  والملخصات/العودة مسجّلة في `data/presence/<userId>.json`.
- **تذكير فوري** من زر «ذكّرني» أو من أي بطاقة روتين.
- يصل عبر **SSE** لحظيًا، و**Web Push (VAPID)** على الأجهزة المشتركة حتى والتطبيق مغلق،
  مع شارة عدّاد على نظام التشغيل. **النقر على الإشعار** يفتح الروتين المستحق مباشرة عبر
  `?focus=` ويميّزه، ويُعلَّم الإشعار كمقروء تلقائيًا.
- **تحكم كامل في الخارج**: تذكيرات الروتين، الإنجازات، أحداث الأنظمة، الملخص اليومي،
  تذكير الغياب، **ساعات الهدوء** (من/إلى) — كلها تُحفظ في الحساب وتُطبَّق على Push،
  مع بقاء كل حدث محفوظًا في الصندوق داخل التطبيق. التنبيهات الأمنية لا تُكتم أبدًا.
- **5 نغمات إشعار** (جرس/همسة/تنبيه/نجاح…) مع مستوى صوت يُحفظ في الحساب، وتُسمع والتطبيق مفتوح؛
  وعند الإغلاق يستخدم النظام صوته الافتراضي (المتصفح لا يسمح بنغمة مخصصة لـ Push).
- **تشخيص وإصلاح ذاتي:** زر «تشخيص» يعرض HTTPS/الإذن/الـSW/الاشتراك/خدمة الدفع، وزر «إصلاح»
  يعيد إنشاء الاشتراك عند تغيّر مفتاح VAPID أو تلفه. الإشعارات تحتاج HTTPS أو localhost.
- إعدادات: تشغيل/إيقاف، دفعة مسائية، خطة صباحية، ملخص يومي ووقته، ورسالة العودة،
  وتذكير الغياب، وأنواع الإشعارات، وساعات الهدوء، ومنطقة زمنية.

## الميزات المُنجزة

### 1) تسجيل الدخول وإنشاء الحساب
- تحقق فوري من الحقول، مقياس قوة كلمة المرور بأربع درجات، إظهار/إخفاء كلمة المرور.
- منع الإرسال المزدوج، أخطاء حقل بحقل، تنبيهات واضحة بالعربية.
- `next=` آمن (مسارات داخلية فقط) للعودة للصفحة المطلوبة بعد الدخول.
- جلسات: كوكي `HttpOnly` + `SameSite` + توقيع HMAC، ومعرّف الجلسة يُخزَّن **مجزَّأً** فقط.
- كلمات المرور: **scrypt** بملح عشوائي لكل مستخدم، وموازنة زمن عند بريد غير موجود.
- حماية **CSRF** بالرأس + Double Submit Cookie لكل طلب تعديل.
- قفل مؤقت بعد محاولات دخول فاشلة متكررة، وحدّ طلبات لكل مسار.
- تغيير كلمة المرور يُنهي كل الجلسات (بما فيها الحالية).

### 2) نظام الإشعارات
- إشعار ترحيب تلقائي عند إنشاء الحساب.
- **بث لحظي SSE**: يصل الإشعار دون تحديث الصفحة، ويعيد الاتصال تلقائيًا بتأخير متزايد.
- شارة عدّاد في الهيدر، تصفية (الكل/غير المقروء)، تعليم الكل كمقروء، حذف فردي أو كلي.
- **Web Push حقيقي (VAPID)** عبر Service Worker: يصل والجهاز مغلق، مع مفاتيح تُولَّد تلقائيًا
  وتُحفظ في `data/push-vapid.json` أو تُضبط من البيئة.
- **إدارة القنوات من صفحة الإشعارات**: تفعيل/إيقاف هذا الجهاز، إشعار تجريبي، وعرض الأجهزة المشتركة.
- **بانر «ما فاتك»**: عند العودة بعد غياب يظهر عدد الإشعارات غير المقروءة وما وصل أثناء الغياب.
- **تصفية بالنوع** (تذكيرات/ملخصات/إنجازات/النظام/ترحيب/أمان) + بحث + تجميع حسب اليوم.
- **ملخص يومي ورسالة عودة وحصاد أسبوعي** من الخادم، وتنبيهات أمان وإنجازات — كلها تُحفظ في الصندوق
  ثم تُدفع للأجهزة، فلا يُفقد شيء لو كان العميل مغلقًا.
- واجهة `notify()` جاهزة لأي ميزة قادمة: روتين اليوم، تذكير مقال، إنجاز…

### 3) ★ الحفظ القوي (الخزنة)
- **تشفير AES-GCM 256** بمفتاح يُولَّد في المتصفح وغير قابل للاستخراج (`extractable: false`).
- **كتابة على مرحلتين**: مسودة ثم تأكيد — انقطاع الكهرباء لا يُفسد البيانات.
- **نسخة احتياطية ثانية** على نظام ملفات المتصفح (OPFS) مستقلة عن القاعدة.
- **نسخ سابقة** لكل حفظ + **سلة محذوفات** (حذف ناعم مع استعادة).
- استعادة تلقائية عند اكتشاف تلف، ومحاولة دائمًا عبر ثلاث طبقات.
- على الخادم: كتابة ذرّية **متوافقة مع ويندوز** (`bak.<name>` + إحلال ذرّي).
- طلب **تخزين دائم** من المتصفح، وقابل للجوال (متاح في الخزنة).

### 4) تطبيق قابل للتثبيت (PWA)
- `manifest` كامل + أيقونات 192/512/maskable + أيقونة Apple.
- `display: standalone` — يُفتح كتطبيق بلا شريط عناوين.
- **يعمل دون إنترنت**: كاش القشرة + استراتيجيات (شبكة أولًا للصفحات وJS، كاش للأصول).
- تحديث تلقائي لـ Service Worker عند نشر نسخة جديدة، وصفحة أوفلاين أنيقة.
- خطوات تثبيت مخصّصة لكل نظام (أندرويد / آيفون / حاسوب).

### 5) تجربة المستخدم
- تصميم عربي RTL كامل، وضع فاتح/داكن/حسب النظام (محفوظ في التفضيلات).
- متجاوب من 360px إلى الشاشات الكبيرة، وحالات فراغ وتحميل (skeleton) واضحة.
- تنبيهات عائمة، احترام `prefers-reduced-motion`، وتسلسل هيكلي صحيح للوصول.

## الأمان والتشغيل

- رؤوس **Helmet** + CSP صارمة + HSTS في الإنتاج + `no-referrer`.
- لا كاش لأي استجابة API (`no-store`)، ولا كاش لأي بيانات مستخدم.
- `SESSION_SECRET` إلزامي في الإنتاج (الخادم يرفض الإقلاع بدونه).
- بيانات التشغيل في `data/` — خارج git، وخارج صورة Docker.

**Docker:**

```bash
echo "SESSION_SECRET=$(node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))")" > .env
docker compose up -d --build
```

**نسخة احتياطية دورية** (cron / Task Scheduler):

```bash
node tools/backup.mjs --keep 14
```

## النشر

هذا تطبيق Express كامل وليس موقعًا ثابتًا؛ لا يعمل على Netlify وحده.
الطريقة الموصى بها:

1. **Render** لتشغيل الخادم مع قرص دائم (`render.yaml` + `Dockerfile`).
2. **Netlify** للواجهة والأصول فقط، مع Edge Function تمرّر الصفحات و`/api`
   إلى Render عبر متغير `BACKEND_ORIGIN`.

الدليل الكامل خطوة بخطوة في [`DEPLOY.md`](DEPLOY.md).

> خطأ Netlify الشائع `publish directory dist does not exist` سببه أن مخرجات
> `npm run build` كانت `public/` فقط. الآن البناء ينسخها إلى **`dist/`**،
> و`netlify.toml` يضبط `publish = "dist"` ويمرّر الصفحات/API إلى الخادم.

## خطوات مقترحة لاحقًا

هذه الميزات مصمّمة لتُضاف كمجلدات جديدة بلا تعديل ما سبقها:

- **مجلتي** (`features/journal`): محرر مقالات يعتمد على `features/save` — الواجهة جاهزة.
- **بريد إشعارات اختياري**: القناة `email` جاهزة في واجهة القنوات، ويحتاج ربط مزوّد SMTP.
- **تفعيل البريد**: نموذج الاستعادة جاهز لإضافة تدفق إعادة تعيين كلمة المرور.
- **مساعد قراءة ببصيرة أوسع:** ضبط `AI_VISION_MODEL`/مزوّد يدعم الصور يفتح شرحًا أدق للرسوم داخل الكتب.
